# Решение за пускане по сигурност — 2026-11-18

Речник: GO / CONDITIONAL GO / NO GO. Решенията важат за състоянието на този клон след сливане; нищо не е разгърнато.

| Повърхност | Решение | Основание и условия |
| --- | --- | --- |
| Публичен маркетингов сайт (текущ) | **GO** за съществуващото; **CONDITIONAL GO** за следващия Release | Работи, Release `44116233973` е зелен и Uptime е зелен. Условие за следващия Release: `db-role-check` = 0, копиран `compose.yml` ([OWNER_ACTIONS](SECURITY_OWNER_ACTIONS_2026-11-18.md)) |
| Административен панел | **CONDITIONAL GO** | MFA е реализирана и тествана; задължителността в производство и Cloudflare Access **не са проверени** — `mfa-status`, Access |
| Клиентски акаунти | **NO GO** | `main` без втори рецензент (SEC-A01); e2e за акаунти не върви в GitHub CI; поща (SPF/DKIM/DMARC), срокове и юрист — непотвърдени |
| Клиентски портал | **NO GO** | динамична междунаемателна проба не е изпълнена; изискванията по акаунти |
| Качване на файлове | **NO GO** | няма скенер, квоти, проверено копие, независим преглед; гейтът остава затворен |
| Плащания и абонаменти | **NO GO** | Stripe е проверен само с фалшив шлюз; няма тестов режим, подписан webhook и правна проверка |
| ИИ модули | **CONDITIONAL GO** само за текстови, без инструменти | **NOT RE-EXAMINED** в този проход; важи [решението от 2026-11-17](../SECURITY_RELEASE_DECISION.md) |
| Пълно активиране на платформата | **NO GO** | сума от горните |

## Критерии — какво е и какво не е изпълнено
- Потвърдени P0: **няма**. Потвърдени P1, поправими в кода: **няма нови**. P2, поправими в кода (SEC-05, SEC-A02, SEC-A03): поправени или обезопасени с тест; не са включени в производство.
- Няма включена недовършена функция; флаговете са непроменени; BG/EN кодът не е пипан.
- **Не е изпълнено:** строг CSP; скенер за файлове; проверка на Cloudflare, сървър, пощенски доставчик и Stripe; нови противникови тестове за API, ИИ, плащания и качване; ZAP/Lighthouse/достъпност; проба за възстановяване; независим рецензент.
- Всичко непроверено е маркирано **NOT VERIFIED**, не **PASSED**.

## План за връщане
Отмяна на комитите на клона. `RATE_LIMIT_BACKEND` е `memory` по подразбиране, така че само промяната на `.env` е нужна, ако е включен `postgres`.
