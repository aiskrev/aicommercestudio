# Окончателно решение за пускане — 2026-11-18

GO / CONDITIONAL GO / NO GO. Важи за състоянието на PR #107 след сливане; нищо не е разгърнато.

| Повърхност | Решение | Основание |
| --- | --- | --- |
| Публичен маркетингов сайт | **CONDITIONAL GO** за Release на `main`+#107 | текущият Release е зелен и сайтът здрав; условия: `db-role-check` = 0, `.env` с `API_DB_*`, копиран `compose.yml` ([OWNER_ACTIONS](SECURITY_OWNER_ACTIONS_2026-11-18.md)); новите променливи (`RATE_LIMIT_BACKEND`, `SECURITY_*`) са по подразбиране безвредни |
| Администрация | **CONDITIONAL GO** | MFA реализирана и тествана; изисква `mfa-status` → `missing: 0`, после `ADMIN_MFA_REQUIRED=true`; Cloudflare Access пред `/admin/*` — не е приложен; средата `production` не е с независим рецензент |
| Клиентски акаунти | **NO GO** | поща (SPF/DKIM/DMARC), срокове и юрист непотвърдени; нито една динамична междунаемателна проба срещу работеща среда; един администратор в хранилището |
| Клиентски портал | **NO GO** | същото + непроверена изолация в работеща среда |
| Качване на файлове | **NO GO** | няма скенер и карантинен конвейер, квотата на работно пространство е добавена (200 MiB по подразбиране), няма копие на тома `project_files`, независим преглед; гейтът остава `False` |
| Плащания | **NO GO** | Stripe е проверен само с фалшив шлюз и локални тестове; няма тестов режим, подписан webhook към истински Stripe, правна проверка |
| ИИ модули | **CONDITIONAL GO** за текстови | платените ИИ маршрути вече отказват (503) при недостъпен споделен лимит, но при `memory` лимитът е на процес; модулите с инструменти не са преразглеждани в този проход |
| Цялата платформа | **NO GO** | сума от горните |

## Остатъчен риск по доказателства
- **Критичен/висок в кода:** няма открит.
- **Среден:** `main` без независим рецензент и без задължителна проверка за deploy конфигурацията (SEC-A01); `production` без независимо одобрение; CSP с `unsafe-inline` (SEC-04); API ролята и задължителната MFA не са проверени на сървъра; Cloudflare/Access/WAF не са проверени.
- **Нисък/информативен:** `postgres` образ без digest; HSTS без `preload`; `security.txt` непубликуван до решение за контакт.
- **Не е изпълнено:** скенер и квоти за файлове; проверка на реално копие; сигнал за 5xx; Stripe в тестов режим; поща.

## Препоръка
Слейте PR #107 след зелен CodeQL; Release е допустим само след условията по-горе. Не включвайте файлове, плащания, акаунти и портал.
