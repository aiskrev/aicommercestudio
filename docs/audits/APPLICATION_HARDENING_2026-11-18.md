## Следващи стъпки за приложението (в реда на полезност)
1. На сървъра: `sudo docker exec $(sudo docker ps -qf name=ai-commerce-studio-api) python -m app.cli mfa-status`; при `missing: 0` — `ADMIN_MFA_REQUIRED=true` (с одобрение).
2. Измерване на ресурсите на VPS преди втори работен процес (сега: db 768 MB + api 640 MB + web 640 MB от 4 GB; допълнителните процеси на API делят същия лимит от 640 MB на контейнера, затова се мери паметта на процес преди увеличение).
3. CSP Report-Only в тестова среда с приемник на отчети — отделен проект.
4. Скенер за качени файлове — решение за ресурс/сървър, после реализация.
