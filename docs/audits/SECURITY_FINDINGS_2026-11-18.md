## Решение за FORCE ROW LEVEL SECURITY (SEC-A03)
Не се прилага сега. `acs_app_api` не притежава таблици и няма привилегии върху тенант таблиците без обвързване; обвързаната роля `acs_app_runtime` е `NOBYPASSRLS`, така че политиките вече важат за всички пътища, които API ползва. `FORCE` би засегнал само собственика на схемата (миграции, `maintenance`, CLI) — тоест би рискувал да счупи именно тези законни задачи, без да затваря реален път. Преразглеждане: само след тест на всяка CLI команда, изпълнявана като собственик.

## SEC-04: път към строг CSP (не е изпълнен)
1. Начало с `Content-Security-Policy-Report-Only` само в тестова среда. Приемник на отчети **не съществува**, така че без него режимът не дава информация.
2. Измерване на TTFB/LCP/INP/CLS преди и след. Nonce означава динамично изобразяване на публичните страници (загуба на статичния кеш), а производственият LCP вече е над 2,5 s — затова не е започвано без измерена изгода.
3. Turnstile (`frame-src`/`script-src`), хидратация, BG/EN, админ и формуляри — тествани поотделно.
4. Връщане: премахване на заглавието.
