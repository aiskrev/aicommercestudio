## Правила за всеки Release
Преди: `db-role-check` в работещия API контейнер = 0 (направено днес); след: HEAD на `/bg`, `/en`, `/api/health/ready`, проверка на `Cache-Control`. Не използвайте „downgrade“ на схемата като връщане.

## Разходи и ограничения
Нищо не изисква покупка. Ограничаването на шифрите (TLS-02) може да е платена функция — не се купува без решение.
