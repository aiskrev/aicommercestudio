* Не е проверено производството (нито за роля на базата, нито за Cloudflare, нито за заглавията на живия сайт); препоръките са по кода и документите.

* Не са пускани GitHub проверките от `security.yml`; необходимо е първо изпълнение след сливане на PR.
* Няма независим човек, който да е прегледал тези резултати.
