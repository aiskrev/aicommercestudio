## 3. Какво не е изпълнено

* GitHub Actions не са пускани (няма изпращане): новите `Secret scan`, `CodeQL`, `Dependency review`, `SBOM` ще се видят при първия PR.
* Не са пускани тестове срещу производството или чужди хостове. Не е измерван INP. Не е тествано на реални устройства или с екранен четец.
* Няма повторение на пакетите по много пъти; „зелено“ е един окончателен пуск, не статистика за стабилност.
